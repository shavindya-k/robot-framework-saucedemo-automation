# Robot Framework - SauceDemo Test Automation

A UI test automation project built with Robot Framework and SeleniumLibrary, using a Page Object Model (POM) structure to automate and validate web application scenarios.

This is a personal project I created to learn, improve, and further practice my skills in Robot Framework and test automation.

The project contains automated test scenarios for [SauceDemo](https://www.saucedemo.com/), a sample web application commonly used for practicing test automation. I plan to expand the test suite with additional scenarios and testing techniques as I continue learning.

## Prerequisites
Before running the tests, make sure the following are installed:
- Python
- Robot Framework
- Robot Framework SeleniumLibrary
- Robot Framework Pabot (optional at this stage)

The project requires a compatible Python version. Robot Framework and the required libraries can be installed using:
```
pip install -r requirements.txt
```

## IDE Support

A Robot Framework plugin is recommended for improved syntax highlighting, keyword recognition, navigation, and code completion in your IDE.

I'm currently using [Xeon RobotFramework Support](https://plugins.jetbrains.com/plugin/27395-xeon-robotframework-support) with PyCharm.

I initially tried [IntelliBot @SeleniumLibrary Patched](https://plugins.jetbrains.com/plugin/10700-intellibot-seleniumlibrary-patched), but encountered compatibility issues with the latest version of PyCharm, including IDE crashes. Therefore, I chose Xeon as an alternative.

(The IDE plugin is not required to execute the tests. It is only used to improve the development experience).

## Test Scenarios

The automated test suite currently covers positive and negative login scenarios. Additional test scenarios and features will be added as the project evolves.

## Running the Tests

To run the complete test suite:

```
robot tests/
```

To run a specific test suite:

```
robot tests/features/loginTests.robot
```

Test results and reports are automatically generated by Robot Framework after test execution and can be found in the results and reports directories.
